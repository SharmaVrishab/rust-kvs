# kvs

A small Rust project for learning the language by building a key-value store
from scratch.

The repository is currently at the first learning stage: basic Rust syntax,
functions, integer types, and Cargo. The key-value store implementation will
be built incrementally.

## Requirements

- Rust 1.85 or newer
- macOS or Linux

## Run

Run the current example binary with:

```bash
cargo run
```

Check formatting and compile the project with:

```bash
cargo fmt --all -- --check
cargo check
```

Run the test suite with:

```bash
cargo test
```

## Project Status

This project is under active development. The first milestone tests are
intentionally present ahead of the implementation and will turn green as the
learning milestones are completed.
